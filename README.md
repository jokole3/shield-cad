# ЩитCAD 2D + ИИ-инженер на Groq (проект для Vercel)

## Как запустить на Vercel за 2 минуты (бесплатно)

1. Получите бесплатный API-ключ на https://console.groq.com/keys (выглядит как `gsk_...`).
2. Создайте репозиторий на GitHub и загрузите туда файлы из этого архива (или загрузите папку через Vercel CLI: `npx vercel`).
3. Откройте https://vercel.com/new → импортируйте репозиторий → перед нажатием **Deploy** откройте раздел **Environment Variables** и добавьте:
   - **Key:** `GROQ_API_KEY`
   - **Value:** ваш ключ `gsk_...`
4. Нажмите **Deploy** — через ~30 секунд вы получите постоянную ссылку вида `https://your-project.vercel.app`, где работает и 2D-редактор, и встроенный ИИ-инженер без ввода ключа со стороны пользователей.
